# [TE-050] Runtime generator and data functions

Milestone: M7 Export, runtime and preview · Size: L · Depends on: TE-011, TE-049

## Context

Each export writes `ngne-tilemap.ts`, an import-free module games commit and never edit
(BRIEF §6, D9). This ticket builds the generator and the runtime's loading, asset and data API;
drawing is TE-051.

## Required work

- Generator: header `// Generated by ngne-tilemap-editor <version>. Reads ngne-tilemap versions
  1..1. Do not edit.`, the runtime source with `emit.ts` inlined (no imports in the output), then
  the folder's tables `TILEMAP_URLS`, `ATLAS_URLS`, `IMAGE_URLS` (each URL
  `new URL("./<file>", import.meta.url).href`) and the `TilemapName`, `TilesetName` types.
- `readTilemap` (reader + atlas checks, migrations, new objects and a mutable `Uint32Array` per
  layer each call); `loadTilemap` through the URL tables with an abort signal.
- `assetsFor(tilemap, imageAsset)`: one asset per tileset and image, IDs
  `ngne-tilemap:<project>/<exportName>`, definitions cached at module level by ID.
- Data functions in map pixels at parallax 1 (offsets included): `findLayer`, `tileAt`,
  `classAt`, `propertyAt`, `grid`, `collisionShapes` (orientation about the content centre,
  FORMAT §1.3 placement), `collisionRects` (row runs, then equal x-ranges in consecutive rows),
  `markers` with filters; cells outside the map empty.
- Per-layer caches for `grid`, `collisionShapes`, `collisionRects`; `setCell` writes and drops
  the cache; `invalidate` drops it after direct `data` writes.

## Acceptance criteria

- [ ] `tests/unit/te-050-generator.test.ts`: generated source has no `import`, the header, the
      tables and the name types; same tables → same bytes.
- [ ] `tests/unit/te-050-data.test.ts`: each function against hand-computed results on the meadow
      fixture and a rotated-tile fixture; `collisionRects` merges a known layout into the expected
      rectangles deterministically.
- [ ] `assetsFor` returns identical objects across calls; IDs namespaced.
- [ ] `setCell` and `invalidate` refresh cached results; mutating one `readTilemap` result does
      not affect another.
