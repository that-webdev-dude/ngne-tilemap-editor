# End-to-end tests

Playwright specs against the dev server in installed Chrome (`npx playwright test`; settings in
`playwright.config.ts`). A spec is named after its ticket, `te-0xx-*.spec.ts`; shared helpers
are `te-0xx-support.ts` and `support/`; page modules and pages the specs load are in `harness/`.

- A test whose result depends on how many animation frames arrive in a span of time has
  `@alone` in its title. It runs in the `alone` project, after every other test, one at a time.
- CI runs the `parallel` project in four shards and `alone` in a job of its own, headed Chrome
  under xvfb with SwiftShader WebGPU, one worker per job, no retries. The golden path also runs
  10 times in a row in a job of its own (`ci.yml`, `golden-path`).
- A local run with `CI=1` uses CI's workers, timeouts, retries and software WebGPU adapter;
  it is headless unless `E2E_HEADLESS=0`, and on Windows Chrome takes no Vulkan flags.
  `E2E_WORKERS` sets the worker count for a headless run.

The golden path, `te-063-golden-path`, runs the whole loop through the interface: new project →
import a grid PNG and a `.ngsprite` → bucket fill, stamp and terrain brush → layers, a marker and

export as the compositor draws the saved project.
